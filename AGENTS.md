# AGENTS.md — CPA Landing

Контекст для AI-агентов (Claude Code, Copilot, и пр.), работающих в этом репозитории. **Это единственный источник истины.** Файл `CLAUDE.md` — заглушка, которая ссылается сюда.

---

## 1. О проекте

Web-приложение CPA — лендинг с постраничным перелистыванием на десктопе и адаптивной мобильной версией. Контент частично загружается с API, на странице доступны несколько языков (en — по умолчанию, ru — `/ru`, далее `/es` и пр.).

- Макет: [Figma](https://www.figma.com/design/U9mPOGl2XWFWVq5Uttc1JK/CPA-F?node-id=4134-4449)
- API docs: https://cpa-server-vtel.onrender.com/api-docs
- API base: `https://cpa-server-vtel.onrender.com/<locale>/...` (по умолчанию `en`)
- Авторизация: header `x-api-key` (значение — в `.env`, **не коммитим**)

> ⚠️ Сервер может «холодно стартовать» — первый запрос после 20 минут простоя занимает 30–40 сек. Имеет смысл использовать прелоадер.

## 2. Стек

- **Nuxt 4** (`^4.4.5`) + **Vue 3** (`^3.5.34`) + **vue-router** (`^5.0.6`)
- **TailwindCSS 4** (`^4.3.0`) через `@tailwindcss/vite`
- **TypeScript** (через `nuxt prepare` — конфиги в `.nuxt/`)
- Кастомные шрифты: **Halvar Breit** (заголовки) и **Stolzl** (текст)

## 5. Ключевые требования (выжимка из ТЗ)

### Поведение и UX

- **Десктоп**: постраничное перелистывание, каждая страница — `100vh`, контент адекватно умещается.
- **Мобильная версия**: без переходов/анимаций между секциями (оптимизация). Остаются только бегущая строка и переключающаяся строка.
- Скролл колесом мыши = **1 шаг = 1 переход**. Обязательно работает **в обе стороны**.
- Локальные ссылки ведут сразу на нужный блок; переход назад/вперёд после этого работает корректно.
- Хедер 1-го экрана: ссылки — это локальные якоря на страницы 2, 3, 4 по порядку.
- На последней странице кнопка «Scroll to top» возвращает на 1-й экран.
- Каждая кнопка на 4-м экране триггерит модалку.
- При открытии модалки фон **обязательно** блюрится.

### Анимации

- Фоновая анимация — постоянная; на 2-м экране затемняется оверлеем.
- Анимация бегущей строки (3 экран) и переключающейся строки (1 экран) — **бесконечные**.
- Все анимации работают плавно во всех современных браузерах (см. [browserslist baseline](https://browsersl.ist/#q=baseline+widely+available)).
- Анимация фона может отличаться по размеру/таймингу от макета — это допустимо. Остальные — строго по макету.

### Формы и контакты

- Форма обратной связи: имя — опционально, остальные 2 поля — обязательны.
- Методы контакта: **Telegram, Whatsapp, Email**.
- Окно благодарности **не закрывается само** по таймеру.
- Ссылки на соцсети — заглушки `#`.

### i18n

- `/` — английская версия (default).
- `/ru`, `/es`, ... — другие языки.
- Локальные якоря работают через языковой префикс: `/es#join`.

### API

- Все запросы — с заголовком `x-api-key` (ключ хранится в `.env`, в репо не попадает).
- Локаль — в URL: `https://cpa-server-vtel.onrender.com/ru/benefits`.
- Без локали → `en`.

### Стиль

- Pixel-perfect **не требуется** по расположению (проект под разные экраны, особенно 13").
- Размеры текстов и элементов — **по макету**.
- Есть фиксированный контейнер по ширине.
- Желательно запретить выделение картинок со змеями (не критично).

### Качество

- Lighthouse desktop & mobile: **Performance ≥ 75**, остальные категории **≥ 90**.
- В финальном коде — **без `console.*` и комментариев-черновиков**.

## 6. Конвенции для агентов

- Перед изменением визуала — сверяться с Figma по указанному node-id.
- Шрифты подключены через `@font-face` в [app/assets/css/fonts.css](app/assets/css/fonts.css); токены — в [app/assets/css/main.css](app/assets/css/main.css) (`--font-sans`, `--font-stolzl-book`, `--font-halvar`). Заголовки `h1..h6` уже привязаны к Halvar в `@layer base`.
- Tailwind 4 настроен через vite-плагин в [nuxt.config.ts](nuxt.config.ts) — отдельный `tailwind.config` не нужен, кастомные токены живут в `@theme {}` блоке main.css.
- **Никогда не коммитить секреты** (API-ключи, токены) — только через `.env` (см. `.gitignore`).
- Не коммитить `console.log` и закомментированный код.
- Картинки со змеями — `user-select: none` / `pointer-events: none` на превью (как только начнём верстать).
